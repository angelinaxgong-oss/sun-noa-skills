# Meeting Minutes Glossary (CN⇄EN)

## 1. Document structure words
| 中文 | English |
|---|---|
| 会议纪要 | Meeting minutes |
| 会议信息 | Meeting information |
| 参会人员 | Attendees |
| 议题 | Topic / Agenda item |
| 重要安排 | Key arrangements |
| 决定事项 / 会议决定 | Decisions |
| 后续行动 / 行动项 | Action items |
| 待办 | To-do / Pending |
| 下次会议 | Next meeting |
| 其他事项 | Any other business (AOB) |

## 2. Record language
| 中文 | English |
|---|---|
| 会议以中英混合进行，我方提供口译 | The meeting was conducted in a mix of Chinese and English, with interpretation provided by our side |
| 会上讨论/谈及 | The meeting discussed / touched on |
| 双方同意 | Both sides agreed |
| 达成一致 | Reached consensus |
| 待确认 | To be confirmed |
| 另行商定/另行确定 | To be agreed separately / to be confirmed at a later stage |
| 我方将跟进 | Our side will follow up |
| 对方将内部讨论 | The other side will discuss internally |
| 如条件允许 | When feasible / if conditions allow |
| 时间待定 | Date TBD |
| 如有遗漏或出入之处，欢迎随时指出，我们将及时补充修订 | Should anything be missing or inaccurate, please feel free to let us know, and it will be revised promptly |

## 3. Role & company words
| 中文 | English |
|---|---|
| 我方 | Our side |
| 对方 / 贵司 | The other side / your company |
| 海外组 | Overseas division |
| 负责日常与订货 | Handles daily operations & ordering |
| 英文翻译 | English interpreter |
| 口译/记录 | Interpretation & minutes |
| 联系人 | Contact person |
| 宫总 / 吴总（沈阳/北京） | Mr. Gong / Mr. Wu (Shenyang/Beijing) — CN leadership address (总 = boss/GM) |
| 交接/接管市场 | Handover / take over a market |

## 4. Common meeting verbs (past, neutral)
| 中文 | English |
|---|---|
| 确认 | Confirmed |
| 提议 | Proposed |
| 同意 | Agreed |
| 希望/期待 | Would like to / looks forward to |
| 将考虑 | Will consider |
| 计划于 | Plans to (e.g., plans to visit in November) |
| 自…起 | From … onward (e.g., from October) |
