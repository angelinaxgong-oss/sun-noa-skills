# TDS Glossary (CN → EN, unified)

## 1. Section Headers (FIXED output names)
The CN section names below are FIXED and must be used EXACTLY in the CN output. Do NOT substitute synonyms.

| CN (output, fixed) | EN (output, fixed) |
|---|---|
| 产品描述 | Product Description |
| 特点 | Characteristics |
| 技术参数 | Technical Specification |
| 施工参数 | Application Parameters |
| 注意事项 | Precautions |
| 安全事项 | Safety (subsection inside 注意事项) |
| 储存 | Storage (subsection inside 注意事项) |
| 清洁 | Cleaning (subsection inside 注意事项) |

Note: 安全事项, 储存 and 清洁 are subsections INSIDE 注意事项. Their names are flexible and may follow the source wording (e.g., 安全, 贮存, 储存条件, 清洗方法). The top-level names above are the only strictly fixed ones.
| 保质期 | Shelf Life (always blank) |
| 包装 | Packaging (always blank) |
