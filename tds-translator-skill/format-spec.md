# TDS Format Specification (docx, English)

This file defines the EXACT formatting for generated English TDS Word documents.

## 1. Page Setup
- Page size: Letter (11906 x 16838 twips)
- Margins (twips): top=1361, right=751, bottom=884, left=1785
- Header distance: 688, Footer distance: 716

## 2. Fonts
- Default body font: Arial, 10.5pt (sz=21)
- Table font: Helvetica Neue, 9.5pt (sz=19)
- Header/footer font: 9pt (sz=18)

## 3. Line Spacing
- Body and headings: 1.5 line spacing (w:line=360)
- Table cells: w:line=300

## 4. Header (repeating on every page)
- Line 1: "Technical Data Sheet" (bold)
- Line 2: "Beijing SUN-NOA Technology Development Co., Ltd."
- Line 3: "Tel: +86-10-85365010 | Add: Room 504, Building 2, Tuqiao PLUS Cultural and Creative Industrial Park, Tongzhou District, Beijing, China"
- Line 4 (right): "[Date] | page 1 of 1 page"

## 5. Footer (repeating on every page)
- Disclaimer text (9pt)

## 6. Product Name
- Font: Arial, 15.5pt (sz=31), bold

## 7. Section Headings ("Application", "Characteristics", etc.)
- Font: Arial, 15.5pt (sz=31), bold
- Spacing before: 93

## 8. Body Text
- Font: Arial, 10.5pt (sz=21)
- Spacing before: 52
- Left indent: 29

## 9. Tables (Technical Specification)
- Font: Helvetica Neue, 9.5pt (sz=19)
- Borders: none
- Header row: not bold

## 10. Disclaimer (bottom)
- Font: Arial, 9pt (sz=18)
